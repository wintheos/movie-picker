# Вечером — что посмотреть сегодня

Прототип сервиса, который за 2–3 минуты помогает выбрать фильм на вечер.

**Живой прототип:** https://wintheos.github.io/movie-picker/

## Идея

Пользователь пришёл домой уставшим и не хочет листать каталог. Поэтому сервис:

1. **Задаёт один вопрос** — «Какое настроение сегодня?» (три крупные карточки, никаких фильтров).
2. **Сразу показывает 4–6 фильмов.** Время и компанию можно уточнить в дропдаунах над подборкой — подборка пересчитывается мгновенно.
3. **Ведёт на страницу фильма** с ответом «Почему подойдёт сегодня» и кнопками решения.

Фишка — кнопка **«Выбрать за меня»**: случайный фильм из текущей подборки (на главной — из всех).

### Как работает подбор

Мягкое ранжирование вместо жёсткого фильтра, поэтому экран никогда не бывает пустым. Для каждого фильма считается, сколько выбранных уточнений совпало (`k из N`). Сначала идут полные совпадения, потом частичные, внутри группы — по рейтингу. Метка на постере показывает степень совпадения.

## Запуск локально

Нужен любой статический сервер (данные грузятся через `fetch`, поэтому двойной клик по `index.html` не сработает):

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000/

## Устройство

```
index.html     — единственная страница
style.css      — стили (токены цветов в :root, брейкпоинт телефона ≤ 720 px)
app.js         — hash-роутер, подбор, экраны
movies.json    — данные: фильмы и подписи фильтров
posters/       — постеры
fonts/         — Playfair Display и Manrope (woff2, кириллица + латиница, OFL)
```

- Чистые HTML/CSS/JS без сборки и зависимостей, без внешних запросов.
- Всё состояние — в адресе (`#/results?mood=think&time=mid&who=couple`, `#/movie/3?...`), поэтому F5 и ссылки работают на любом экране.
- Подписи фильтров и границы времени берутся из `movies.json` — их можно менять без правки кода.

Рейтинги — по данным Кинопоиска. Постеры и описания принадлежат правообладателям и используются в учебном прототипе.
